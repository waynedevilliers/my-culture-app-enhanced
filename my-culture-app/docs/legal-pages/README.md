# Impressum, Datenschutz and icons

- `/impressum` holds the official Impressum of Culture Academy e. V. (Halle/Saale, Vereinsregister 22292, Amtsgericht Stendal), as supplied by the operator.
- `/datenschutz` holds the official Datenschutzerklärung of Culture Academy e. V., as supplied by the operator.
- Both pages use the light page background like the other pages, with a top margin that matches theirs (the heading starts 56 px below the navbar on desktop).
- The old address `/privacy` redirects permanently to `/datenschutz`.
- `public/logo/favicon.ico` (16/32/48 px) and `public/logo/apple-touch-icon.png` (180 px) are made from the "o" of the grow logo.

Note for the operator: the Datenschutzerklärung was written for culture-academy.org. It describes Usercentrics/eRecht24, a contact form and eCommerce, which this app does not use, and it does not yet mention the services this app does use (hosting on Vercel, database on Neon, file storage, login data in the browser's local storage). Have it checked before relying on it.
